# Git Commands to Commit or Stash Changes Before Switching Branches

## Option 1: Commit Your Changes
If you want to commit your changes before switching branches, follow these steps:

1. **Add changes to staging**:
   ```bash
   git add .



Commit the changes:
git commit -m "Your commit message here"



Switch to the PDF-Works branch:
git checkout PDF-Works



Option 2: Stash Your Changes
If you want to temporarily save your changes without committing them, follow these steps:


Stash the changes:
git stash



Switch to the PDF-Works branch:
git checkout PDF-Works



Apply the stashed changes later:
git stash pop
